Gerado direto da API do Meta Ads
Gere em Graph API Explorer com a permissão ads_read. Para um token que não expira, use um System User no Business Manager.
Encontra em Gerenciador de Anúncios → Configurações da conta.
Escolha o dia inicial e o final. Ao mexer nas datas, o período vira "Personalizado".
Como funciona
Tudo roda no seu navegador — os dados vão direto do Meta para esta página, sem passar por nenhum servidor intermediário. Seu token não é salvo em lugar nenhum.
